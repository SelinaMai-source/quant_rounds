### 0.3 策略一句话

在 **D 日收盘确认“硬首板”** 的股票上，用 D 日可得因子给次日溢价/连板潜力打分；**D+1 开盘买入**（开盘一字涨停买不到则放弃）；默认 **从 D+2 起找第一个可卖收盘价卖出**，若继续收盘涨停则持有延期。利润高度依赖少数连板右尾，普通交易期望为负。这不是低换手选股。5000 组搜索尚未锁定赢家；当前描述性五组见第 12 节。

## 3. Hermes v7 快照：每张表

**路径：** `/data1/stock-mxy/data/datasets/hermes-cn-a-2010-20260724-v7-all-features/`  
**读取：** `zyquant.data.DataSnapshot(...).table(表名, start, end, cutoff, fields=...)`  
**适配器：** `HermesDataAdapter`  
**schema_version：** `1.2`  
**质量：** `quality.status = passed`；`raw_adjusted_key_match = true`  
**能力标记：** `capabilities.backtest_ready = false`  
**原因原文：** `"Hermes does not contain a confirmed complete historical commission/tax/transfer-fee rule series"`  
因此一进二**不使用**快照内 `market_rules` 做费用，而是代码硬编码费用。

复权：

| 项 | 值 |
|---|---|
| materialized | true |
| method | `vendor_post_adjusted` |
| algorithm_version | `hermes-af-1.0` |
| anchor | Hermes `ACCUM_ADJ_FACTOR_2` |
| factor_source | vendor |
| event_adjustments | 55001 |

PIT 通用规则（资金流/涨停事件/融资融券/日内因子）：  
`available_at = max(trade_date, source_updated_at 转 Asia/Shanghai 的日期)`。

日频行情表按 `year=YYYY/month=MM/part-YYYY-MM.parquet` 分区。

### 3.1 `daily_raw` — 未复权日行情（最核心）

| 项 | 内容 |
|---|---|
| 含义 | A 股未复权 OHLCV、停牌、涨跌停价 |
| 路径 | `.../daily_raw/year=*/month=*/part-*.parquet` |
| 行数 | 14,522,056 |
| 粒度 | 日频，股票×交易日 |
| 覆盖 | 2010-01 至 2026-07-24（分区存在这些年） |
| 主键 | `(trade_date, instrument_id)` |
| 复权 | **未复权** |
| 字段 | `trade_date, instrument_id, open, high, low, close, pre_close, volume, amount, paused, limit_up, limit_down, source_record_id, source_updated_at` |
| 单位 | 价格元；volume 股；amount 元；paused bool |
| 缺失 | `limit_up/limit_down` 覆盖约 99.84% |
| 停牌 | `paused=True` 共 424,336 行；另有 7 行 quarantine |
| 用途 | 硬首板定义、过滤、标签、回测成交、市场涨跌比 |
| 代码入口 | `dataset._compute_daily_features`；`fixed_sleeve_backtest`；几乎所有 tools |

涨停判定（代码，不是表字段）：

\[
\text{tradable} = (\neg paused) \land (volume > 0)
\]
\[
\text{is\_close\_limit} = \text{tradable} \land (close \ge limit\_up - 10^{-4})
\]

容差 `1e-4` 元。创业板/科创板用各自 `limit_up`，不是写死 10%。

### 3.2 `daily_post_adjusted` — 后复权行情

| 项 | 内容 |
|---|---|
| 含义 | 厂商后复权 OHLC |
| 行数 | 14,522,056（与 daily_raw 键对齐） |
| 字段 | `trade_date, instrument_id, open_post, high_post, low_post, close_post, pre_close_post, adjustment_factor, factor_source, adjustment_version` |
| 复权 | **后复权**；`factor_source=vendor`；`adjustment_version=hermes-af-1.0` |

## 5. 数据更新、对齐、缺失、偏差

### 5.1 更新机制

- Hermes v7 是一次性 rebuild，不是每日任务。  
- 要更新必须重新跑 adapter 作业并换 `dataset_id`/fingerprint；因子缓存用 fingerprint 绑定，换快照必须重算。  
- AmazingData 分钟 `source_fetched_at` 样本为 2026-09-01，同样是冻结拉取。  
- ClickHouse 抽取脚本可重跑，但输出目录若已存在会拒绝覆盖（immutable）。

### 5.2 对齐方式

- 键一律 `(trade_date, instrument_id)`。  
- 日日历用 XSHG。  
- 分钟用 `trade_date`（日期）+ `bar_time`（UTC 时刻）。  
- 行业/ST 用 `effective_from/to` + `known_at`。  
- 训练标签成熟：回归/排序要求 `label_end_column <= signal_date`（E2 用 `next2_date`，执行对齐用 `actual_exit_date`）。

### 5.3 缺失处理

数据层（`dataset.py` 文档字符串）：

- **不填补**特征 NaN  
- **不在数据层按特征删行**  
- Inf 转为 NaN  
- 训练折内 `in_memory_complete_cases`：任一活跃特征或（训练时）标签非有限则丢弃，**不改写 parquet**

候选预测宇宙：`candidate_panel` 可以缺标签；**禁止用标签是否存在过滤预测集合**。

过滤层缺失：AI_07.21 `missing_filter_inputs = fail_closed`，缺上市天数/成交额/市值/一字板输入则剔除。

### 5.4 去极值 / 标准化 / 中性化

| 处理 | 是否存在 |
|---|---|
| Winsorize | **无**（明确写在 dataset 模块注释） |
| 行业中性化回归 | **无** |
| 市值中性化回归 | **无** |
| 截面 zscore | 仅 `h8_amount_zscore`、`h8_turnover_rate_zscore`，在 `CN_A_EX_ST` 合格样本上按日标准化 |
| log1p | 成交额、流通市值、总市值、上市天数代理、行业首板计数 |
| 对称变化 | `h5_last_first_limit_value_change_sym` 把变化压到 \([-1,1]\) |
| 模型内 | XGBoost 树模型，无额外标准化 |

### 5.5 复权、停牌、涨跌停（数据层）

- 涨停/买入/卖出价：未复权。  
- 多日收益：后复权 `close_post`。  
- 停牌：`paused` 或 `volume<=0` 视为不可交易。  
- 开盘涨停：`open >= limit_up - tolerance`。回测默认容差 **0.005 元**（`limit_up_tolerance=0.005`）；硬首板/B2 部分用 **1e-4 元**。两套容差不一致，见未确认/风险节。  
- 一字跌停卖不出：`high <= limit_down`（价格在跌停板上完全没离开）。

### 5.6 幸存者偏差

快照含退市股与历史 ST。日行情按当时代码保留。代码切换两例被显式 remap。  
风险点：若某只股票在 Hermes 抽取时被供应商丢掉历史行，本地无法发现；质量报告只保证快照内部 raw/adjusted 键匹配。

## 6. 一进二策略逻辑与全链路

### 6.1 目标叙事

打的是 **首板次日溢价 / 弱转强连板**：D 日第一次收盘涨停，试图在 D+1 买到，吃 D+2 及之后继续封板的右尾。  
研究报告反复写：收益来自低频连板，普通交易亏损，成本吃掉大部分毛利，平均资金暴露低。  
这不是情绪周期择时主策略；情绪/市场涨跌比只是门控或仓位叠加。

### 6.2 选股全链路

```text
Hermes daily_raw
  → 可交易 且 收盘触及涨停
  → 过去 20 个 XSHG 交易日无收盘涨停  ⇒ 硬首板 is_first_board_hard
  → （可选）PIT 去 ST
  → （可选）AI_07.21：上市≥60日、成交额≥5000万、流通市值≥10亿、排除一字板、排除北交所、排除复牌异常
  → 拼接因子（日线 / 资金流 / 涨停事件 / 日内 / 分钟 / 行业）
  → 训练折内 complete-case
  → 模型打分（回归净收益 或 排序 或 触板概率）
  → 按日排序
  → 市场门控 / 开盘缺口 / 分数阈值 / 情绪仓位
  → D+1 开盘下单（拒：停牌、无量、开盘涨停）
  → 持有至可卖出规则触发
```

### 6.3 硬首板定义（入场候选的“一进二”）

代码：`dataset._compute_daily_features`。

1. `tradable = (~paused) & (volume > 0)`  
2. `is_close_limit = tradable & (close >= limit_up - 1e-4)`  
3. 上次收盘涨停的日历指数为 `previous_event_cal`（不含当日）  
4. `no_limit_in_20 = previous 缺失 或 (cal_idx - previous) > 20`  
5. `is_first_board_hard = is_close_limit & no_limit_in_20`

**不含：** 必须全天封死、必须未开板、必须非 ST、必须主板。那些是后续过滤。  
**开板次数：** 硬首板不用开板次数；分钟因子 `fb_touch_count` 是盘中触板次数（供应商口径有问题，见因子节）。

### 6.4 AI_07.21 过滤（研究候选）

代码：`candidate_alignment.apply_ai071_candidate_filters`  
常量：`AI071_FILTERS`

按记录顺序：

| 层 | 条件 | 失败原因码 |
|---|---|---|
| C0 | `is_first_board_hard` | not_hard_first_board |
| ST | `universe_eligible` | ST |
| 上市 | `expm1(g7_listing_days_log) ≥ 60` | listing_days |
| 成交额 | 信号日 `amount ≥ 50_000_000` 元 | amount |
| 流通市值 | `expm1(g0_float_mv_log) ≥ 1_000_000_000` 元 | float_mv |
| 一字板 | `low < limit_up - 1e-4`；缺 high/low/limit 则失败 | one_word_board |
| 北交所 | 代码不以 `.XBEI`/`.XBSE` 结尾 | bj_board |
| 复牌异常 | 上一交易日存在且 amount>0、volume>0、未停牌 | resume_anomaly |

`g7_listing_days_log = log1p(row_number+1)`，`row_number` 是快照 `daily_raw` 内该股从 **history_start=2010-01-01** 起的行号，**不是 IPO 真实日龄**。2010 年前上市的股票，60 日过滤在样本期几乎总是通过。

### 6.5 推荐运行顺序（脚本，无官方 notebook）

一进二没有 notebook 流水线。典型顺序：

1. （一次性）准备 Hermes v7 快照  
2. `tools/cache_first_board_hermes_native.py`

### 8.1 `g_prim_ttl_norm`（封板时间归一化 / Time-To-Limit）

- **中文名：** 首次（或约定）触及涨停的时间归一化  
- **代码名：** `g_prim_ttl_norm`  
- **经济含义：** 越早封板，短线情绪越强，一进二晋级概率往往更高。  
- **公式：** **未能从本仓库 Python 复现。** 只作为 AmazingData 分钟因子缓存列被读入。`first_board_amazingdata_minute_v1/manifest.json` 列为该缓存字段，2022+ 覆盖率 1.0。  
- **审计：** 与原策略共同键上有 727 个有效值不一致、5,601 个缺失状态不一致；**不能当成原 `g8_first_touch_limit_time` 的等价物。**  
- **数据：** AmazingData 1 分钟 high vs Hermes/selection `limit_up`  
- **方向：** 直觉上越小（越早）越好；模型自由学习  
- **使用：** 44 因子输入；排序/回归特征

### 8.2 `g_prim_px_vol_corr`（价量相关）

- **中文名：** 分钟价格与成交量相关  
- **含义：** 价涨量增可能表示真实需求。  
- **公式：** 本仓库无计算代码；来自同一分钟因子缓存。v1 覆盖约 86.8%。  
- **可能越界：** 旧 Hermes 代理 `h_proxy_px_vol_corr` 在全市场也存在 \|r\|>1 的供应商问题；分钟版是否截断**未能从代码确认**。  
- **方向：** 预期为正  
- **使用：** 44 因子输入

### 8.3 `g_prim_prelimit_accel`（封板前加速度）

- **中文名：** 触及涨停前的价格加速度  
- **含义：** 加速上板可能是强势，也可能是尾盘抢筹；对一进二符号不稳定。  
- **公式：** 本仓库无计算代码。审计：650 个有效值不一致、7,693 个缺失不一致。  
- **覆盖：** 分钟缓存约 72.3%  
- **使用：** 44 因子输入

### 8.4 `h_min1_path_eff_full`（分钟路径效率）

- **中文名：** 全日分钟路径效率  
- **代码：** `single_model.compute_minute_extension_factors`  
- **公式：**

\[
\text{path\_steps}_0 = close_0 - open_0,\quad \text{path\_steps}_{t>0}=close_t-close_{t-1}
\]
\[
h = \frac{|close_{last}-open_{first}|}{\sum_t |\text{path\_steps}_t|}
\]

零路径且零位移定义为 1；结果截到 \(\le 1\)。越界则构建失败。  
- **窗口：** 当日全部分钟（完整日 240 根）  
- **数据：** AmazingData 分钟 OHLC  
- **方向：** 越大越“一根直线打到涨停”，封板质量可能更好  
- **使用：** 44 因子；替代旧 `g_prim_path_eff_full`

### 8.5 `fb_touch_count`（触板次数）

- **中文名：** 独立触板回合数  
- **代码意图：** 统计 `high >= limit_up - 1e-4` 从 False→True 的次数，避免按 tick 密度计数。  
- **现实问题：** 单模型资产构建里，该列还会被 Hermes `UP_LIMIT_REACHED_TIMES` 映射覆盖（`MICRO_RENAME`）。审计：最大值 4,208，2,167 条 >240，与原 `g8_open_times` 逐值相等率 0。  
- **因此：** 正式面板里的 `fb_touch_count` **更可能是供应商统计，不是分钟独立回合。**  
- **方向：** 开板过多通常不利一进二；但当前字段语义不可靠  
- **使用：** 仍在 44 因子中；审计建议移出

### 8.6 `fb_last_touch_time_norm`（最后一次触板时点）

\[
\frac{\text{last touch-episode start index}}{n_{\text{bars}}-1}
\]

无触板为 NaN；只有 1 根 K 且有触板则为 0。  
审计：有 <0 或 >1 的行，集合竞价/盘后处理不清晰。

## 10. 标签

### 10.1 `label_e2_gross` / `label_e2_net`（固定 D+2 收盘）

`dataset._attach_labels`：

- 买：D+1 开盘  
- 卖：D+2 收盘  
- 拒绝：没有 D+1/D+2、D+1 停牌/无量、D+1 开盘涨停、D+2 缺收盘；净标签还拒绝 D+2 停牌/无量/收盘跌停  

毛：

\[
\frac{sell}{buy}-1
\]

净（**注意与执行器费用不完全相同**）：

\[
buy_{net}=buy\cdot(1+0.00123)\cdot(1+0.0001)
\]
\[
sell_{net}=sell\cdot(1-0.00123)\cdot(1-0.0001-0.0005)
\]
\[
label\_e2\_net = sell_{net}/buy_{net}-1
\]

此处：滑点 12.3bp、佣金 1bp、印花税 5bp；**没有 0.1bp 过户费**。  
执行器 `ExitLabelCosts` **有** `transfer_fee_bps=0.1`。

### 10.2 `label_exit_rule_net`（与回测对齐，主训练目标）

`labels.attach_exit_aligned_labels`：

- 买：D+1 开盘，经滑点后再夹到 `[max(low,limit_down), min(high,limit_up)]`

- 费用：滑点 12.3bp、佣金 1bp、过户 0.1bp、卖印花税 5bp  
- 买拒绝与执行器共用 `open_buy_block_reason`  
- v6 return labels：26,670 候选中 24,954 有效；买开盘涨停 1,655；买停牌 61；延期退出 1,593；最长 `exit_signal_offset=43`

### 10.3 `label_d1_touch`

D+1 可交易且 `high >= limit_up - 1e-4`。成熟日 = `next1_date`。触板分类器用。

### 10.4 `label_board_chain_relevance`

从 D+1 起连续可交易收盘涨停天数 +1，封顶 5。若 D+1 未收盘涨停：盈利退出=1，否则=0。成熟日=实际卖出日。

### 11.2 成交价假设

- 买：D+1 **开盘价** × (1+滑点)，再夹进当日高低价与涨跌停。  
- 卖（默认）：可卖日 **收盘价** × (1-滑点)，同样夹紧。  
- 可选：`--entry-price-overrides` 用例如 `first_minute_vwap` 作为买价参考。  
- **不是**涨停价成交；开盘已涨停则直接不买。

### 11.3 停牌 / 一字 / 炸板 / 掉队

| 情形 | 处理 |
|---|---|
| D+1 停牌或 volume≤0 | 不买 |
| D+1 开盘涨停（含滑点后仍触及涨停，B2） | 不买 |
| D+2 起收盘涨停 | 不卖，继续持有（连板） |
| 一字跌停（high≤limit_down） | 不卖，等到能离开跌停 |
| 停牌/无量 | 当天不卖，继续找 |
| 炸板但收盘未涨停 | 默认模式在该收盘卖出 |
| `next_open_after_non_limit_close` | 非涨停收盘后，次日开盘卖；开盘跌停则再拖 |
| `ma5_next_open` | 计划日及之后，复权近似价跌破 5 日均则次日开盘卖；或持有满 10 日 |

炸板：没有单独“盘中炸板止损”；默认只看收盘能否卖。

## 13. 买入和卖出点（执行语义）

### 13.1 时间轴

| 时点 | 动作 |
|---|---|
| D 收盘后 | 确认硬首板、算因子、模型打分（不能用 D+1 开盘信息） |
| D+1 开盘 | 买入。T+1 约束：当天买的股票当天不能卖（`sell_delay_days=1`） |
| D+2 收盘起 | 默认卖出窗口 |

没有竞价撮合模拟；开盘价视为集合竞价结果。没有盘中买入、没有尾盘买入（除非改 exit_mode 的卖出）。

### 13.2 买入失败条件（优先级）

执行器 `_buy_block_reason` = `open_buy_block_reason`：

1. 无行情行 → `missing_market_row`  
2. 停牌 → `paused`  
3. volume 非有限或 ≤0 → `zero_volume`  
4. 开盘价无效 → `invalid_open`  
5. `open >= limit_up - 0.005` → `open_limit_up`  

然后可选：

6. 缺 D 收盘 → `missing_signal_close`  
7. `open/D收盘-1 < open_gap_min`（常 -2%）→ `open_gap_too_low`  
8. `> open_gap_max`（常 +7%）→ `open_gap_too_high`  
9. 现金不够一手 → `insufficient_cash_lot`  
10. `score <= minimum_score`：在入场日前就从名单剔除  

B2 另有：市场上涨家数比 <0.45 则整天不买；成交额 <1000 万；滑点后价格越过涨停。B2 在 Top5 里按分数从高到低**第一个通过者**，不是买满 5 个。

触板分类器开盘门控 `apply_open_gate_with_fallback`：`gap_min=-0.02, gap_max=0.07, top_k=3`，按分数回填直到满额。另要求 `eligible_probability`（分数 ≥ 训练基率）。

### 13.3 卖出规则优先级（默认 `close_from_d2`）

每个持仓、每个交易日收盘检查，**仅当 `day >= planned_exit_date`（即 ≥D+2）**：

1. 无行情 / 停牌 / 无量 / 收盘无效 → 推迟  
2. 收盘涨停 → 推迟（连板）  
3. 一字跌停 → 推迟  
4. 否则按建模收盘价卖出  

没有止盈止损百分比。没有“掉队板”独立规则——掉队体现为不再收盘涨停从而卖出。

`next_open_after_non_limit_close`：一旦某日收盘非涨停，就在**次日开盘**卖；开盘跌停再拖。  
`ma5_next_open`：持有天数优先于均线；满 10 个交易日强制次日开盘卖。

### 13.4 仓位

默认等额 4.5 万/票，每日最多 3 票，落在当天轮到的那只袖套的 15 万里。  
动态 NAV 比例、按 rank 不同比例、情绪 `allocation_multiplier∈(0,1]` 都是可选。  
单票没有“占净值上限百分比”的第二层，除非启用 `name_budget_nav_fraction`。

### 13.5 持仓周期

普通交易：D+1 买、D+2 卖，持有 2 个交易日。  
连板：直到收盘不再涨停。标签最长跨 43 个信号偏移。

## 14. 训练配方

### 14.1 XGBRegressor（常用）

`RegressorConfig`：`n_estimators=100, max_depth=3, min_child_weight=1, learning_rate=0.05, subsample=0.8, colsample_bytree=0.8, reg_lambda=1, objective=reg:squarederror, tree_method=hist`。  
滚动：过去 **240 个交易所日历日**，按日等权 sample_weight。  
`min_train_samples=30`。  
单模型脚本默认预测年 2022–2026，`sample_start=2022-01-01`。

### 14.2 XGBRanker

`RankerConfig`：400 树、lr=0.03、depth=6、subsample/colsample=0.85，`rank:ndcg`，默认 5 档日内分箱。  
Walk-forward：**精确过去 3 个日历年训练，下 1 年预测**；标签结束年必须 ≤ 训练期末年。

### 14.3 触板分类器

240 日滚动，`XGBClassifier`，按日归一化权重，正样本权重上限 5。  
选择合同注释：买所有 `predicted_class==1`，不截 TopK。
